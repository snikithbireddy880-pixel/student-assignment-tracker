# Student Assignment Tracker

## Project Goal
This project is a Java program that helps college students keep track of homework, tests, and due dates.

## MVP Features
- Add assignments with names, classes, and due dates.
- View all assignments.
- Mark assignments as completed.
- View upcoming assignments in order of due date.
- Save and load assignments using a CSV file.

## Future Plans
- Add reminders for upcoming assignments.
- Add assignment priorities.
- Add a weekly calendar view.

## Tech Stack
- Language: Java
- Libraries: ArrayList, Scanner, File, and other basic Java libraries
- Data Storage: CSV file
- Version Control: Git and GitHub
- External APIs: None

## How It Works
The program will run in the terminal. Students will use a menu to add assignments, view their work, and mark assignments as completed.
